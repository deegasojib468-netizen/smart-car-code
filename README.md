# Smart Car Code

## 项目简介

本仓库用于保存智能车嵌入式工程代码，硬件平台为逐飞科技 CYT4BB7 双核核心板及 CYT4Bx 主板。工程包含摄像头采集、图像处理、串口通信、无线通信、双核协作和车辆控制等相关内容。

当前提交用于保存已有工程状态，作为后续修改前可回溯的初始版本。

## 打开工程

1. 使用 IAR Embedded Workbench for Arm 9.40.x。
2. 打开工作区：`example/iar/cyt4bb7.eww`。
3. 根据任务选择并编译 CM7_0 或 CM7_1 工程。
4. 下载和调试前确认核心板、DAP、摄像头及串口连接正确。
