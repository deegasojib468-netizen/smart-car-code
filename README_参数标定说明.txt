CYT4BB7 CM7_1 图像参数标定程序 V2
===================================

一、当前程序完成的功能
1. CM7_1 初始化 MT9V03X 摄像头和 DEBUG UART。
2. 将一帧 188x120 灰度图保存到单片机 RAM。
3. 计算最小灰度、最大灰度、平均灰度和大津法阈值。
4. 支持原始灰度图与二值图切换。
5. 支持大津法阈值与固定阈值切换。
6. 通过逐飞助手发送当前保存的图像。

二、关于“把照片存入单片机”
程序中的 snapshot_image 数组会保存一帧图像，大小为 188x120=22560 字节。
它存放在 RAM 中：按键拍照后会一直保留，直到再次拍照、复位或断电。
这不是掉电保存。当前阶段不写内部 Flash，避免频繁擦写 Flash 和增加调试难度。
需要长期保存时，建议先通过逐飞助手保存到电脑；后续再单独增加 Flash 或 SD 卡功能。

三、按键功能
按键定义来自 libraries/zf_device/zf_device_key.h：
KEY1=P20_3，KEY2=P20_2，KEY3=P20_1，KEY4=P20_0。
在主板上对应四个用户按键，实际从上到下的编号请以 PCB 丝印和按下测试为准。

KEY1：保存下一帧图像到 RAM，并发送一次。
KEY2：切换原图/二值图，并重新发送保存的图像。
KEY3：切换大津阈值/固定阈值。二值图模式下会重新发送。
KEY4：只发送一行统计文本，不发送图片。

固定阈值在 main_cm7_1.c 中：
#define FIXED_BINARY_THRESHOLD (128U)

四、测试方法
1. 打开 example/iar/cyt4bb7.eww。
2. 先 Clean + Rebuild CM7_1，再 Clean + Rebuild CM7_0。
3. 把 CM7_0 设为活动工程，下载并运行双核。
4. 逐飞助手选择“图像传输”，115200 波特率。
5. 上电后程序会自动保存并发送第一帧。
6. 按 KEY1 重新拍照；按 KEY2 查看二值图。

五、查看统计参数
图像和统计文本共用 DEBUG UART，建议分开查看：
1. 在“图像传输”页面查看并保存原图或二值图。
2. 切换到“串口助手”页面后按 KEY4。
3. 会收到类似：
   snapshot=2 mode=BINARY threshold_mode=OTSU min=8 max=245 mean=73 otsu=106 active=106

字段含义：
snapshot：第几次保存图像。
mode：当前发送原图还是二值图。
threshold_mode：大津法还是固定阈值。
min/max/mean：最小、最大、平均灰度。
otsu：大津法算出的阈值。
active：当前二值化实际使用的阈值。
