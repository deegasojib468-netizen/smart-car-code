CYT4BB7 CM7_1 白色空心方框识别 V4.1 图像调试版

本版本基于 V4 修改，目标是解决实际图像中白框未识别、串口助手不显示调试文字的问题。

主要变化：
1. 放宽白框识别参数：降低识别阈值、放宽空心区域判断。
2. 不再依赖串口文字判断识别结果。
3. 每次按 S6 发送图像时，图像上都会画出搜索区域 ROI。
4. 如果识别成功：显示黑色识别框和白色中心十字。
5. 如果识别失败：显示黑色 ROI 框，并在图像边缘显示投影调试短线，帮助判断程序看到的亮区域在哪里。

按键功能不变：
S3/P20.3：拍照并保存到 Work Flash。
S4/P20.2：切换下一张已保存图片。
S5/P20.1：切换原图/二值图。
S6/P20.0：识别并发送当前保存图片。

测试方法：
1. 先编译 CM7_1，再编译 CM7_0。
2. 从 CM7_0 下载运行。
3. 打开逐飞助手图像传输，115200。
4. 按 S6 查看当前保存图片。

看图判断：
1. 只有原图、没有任何黑框：请确认已经下载的是 V4.1 版本，并按了 S6。
2. 有一个大黑色矩形框：这是搜索区域 ROI，说明图像调试版已经生效。
3. 有黑色目标框 + 白色中心十字：说明识别成功。
4. 有 ROI 框和很多边缘短线，但没有目标框：说明程序看到了亮区域，但筛选条件仍需继续调整。

说明：
V4.1 仍然是基础识别调试版，不接电机控制。下一步根据截图继续调整 ROI、阈值、宽高范围和空心判断。
