CYT4BB7 CM7_1 脱机拍照与图像标定工具 V3
==========================================

一、功能
1. CM7_1 独占 MT9V034 摄像头。
2. 使用主板四个按键手动拍照。
3. 原始 188x120 灰度图写入单片机 Work Flash，断电不会丢失。
4. 最多保留 7 张原始图；第 8 张开始循环覆盖旧槽位。
5. 每次拍照同时保存最小灰度、最大灰度、平均灰度、大津阈值和校验和。
6. 回到电脑旁后，可以把保存的原图或二值图发送到逐飞助手查看。

二、按键
KEY_1 / P20.3 / 主板 S3：拍摄下一帧并保存到 Flash。
KEY_2 / P20.2 / 主板 S4：选择下一张已保存图片；LED 闪烁次数表示槽位 1~7。
KEY_3 / P20.1 / 主板 S5：切换导出模式；LED 1 次=原始灰度图，2 次=二值图。
KEY_4 / P20.0 / 主板 S6：把当前选中图片发送到逐飞助手，并通过串口输出统计参数。

三、脱机拍照
1. 编译并下载 CM7_1、CM7_0 后，断开电脑。
2. 接好摄像头，使用电池给整车主板供电。
3. 上电后 LED 快闪 2 次表示程序进入工作状态。
4. 调整车辆和白框位置，短按 S3；LED 闪 1 次表示这一帧已保存。
5. 更换距离、角度和光线后重复按 S3。
6. 拍完后可以直接断电，图片保存在 Work Flash 中。

四、回到电脑后查看
1. 给板子供电并连接 DAP-LINK 或 USB-TTL。
2. 打开逐飞助手，进入“图像传输”，选择对应串口，波特率 115200。
3. 按 S4 选择下一张图片。LED 闪几次，就是槽位几。
4. 按 S5 选择原图或二值图。
5. 按 S6，当前图片会传到逐飞助手。
6. 需要查看统计值时，使用逐飞助手串口接收界面，按 S6 后可看到：min、max、mean、otsu 等。

五、编译下载顺序
1. CM7_1：Clean -> Rebuild All。
2. CM7_0：Clean -> Rebuild All。
3. 将 CM7_0 设为活动工程，Download and Debug。

六、注意事项
1. 本工具占用 Work Flash 第 0~84 页，不能和其他也使用这些页的程序混用。
2. Flash 不是 JPG/PNG 文件系统，Windows 文件资源管理器不能直接看到图片。
3. 图片必须由本程序读出，再通过逐飞助手显示。
4. 拍照时摄像头持续采集；按键只是把“下一帧完整图像”写入 Flash。
5. 现场没有电脑时，S4/S5/S6不是必须操作，只需按 S3 拍照。
