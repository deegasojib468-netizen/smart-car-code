# P20_3 旧主板 S3 按键 1.3V 错误记录

## 1. 问题现象

* 旧主板 S3 对应 P20_3。
* 松开按键时，核心板 P20.3 约 1.3V。
* 主板按键节点也约 1.3V。
* 按下可以到 0V，但松开不能回到 3.3V。
* 程序可能因此误判 K3，导致 S2 -> S3 无法可靠触发。

## 2. 正常电气逻辑

* 旧主板 S3/S4/S5/S6 是上拉输入、按下接 GND。
* 松开应接近 3.3V。
* 按下应接近 0V。
* 1.3V 是异常中间电压，不能当作正常高电平。

## 3. 与 P06_4 / U8 历史错误的关系

* P06_4 曾经出现 1.4V / 0.4V。
* P06_4 后来通过完整 GPIO 输入上拉恢复正常。
* 关键配置包括：
  `HSIOM = HSIOM_SEL_GPIO`
  `driveMode = CY_GPIO_DM_PULLUP`
  `outVal = 1U`
  input buffer on
  避免后续初始化覆盖
* P20_3 已按类似规则处理后仍为 1.3V，所以硬件拖低、主板上拉异常或核心板引脚拖低优先级更高。

## 4. 最快硬件隔离步骤

1. 断电。
2. 拔下核心板。
3. 只给旧主板供电。
4. 量 S3/P20.3 节点。
5. 如果拔下核心板后变 3.3V，说明旧主板上拉正常，是核心板/代码/芯片拖低。
6. 如果拔下核心板后仍为 1.3V，说明旧主板 S3 电路异常。
7. 断电测 P20.3 对 GND 电阻。
8. 检查 R45 上拉电阻、S3 按键、焊接、污染、VCC3V3、短路。
9. 不要先改状态机。

## 5. 临时绕过方案

* P20_3 只做诊断。
* P20_1 / S5 临时作为 S2 -> S3 测试键。
* P20_2 / S4 保持 S3 -> S0。
* P20_0 / S6 保持复位。

## 6. 结论

P20_3 松开只有 1.3V 时，不应继续作为状态机按键使用。必须先完成硬件隔离或临时更换按键。
