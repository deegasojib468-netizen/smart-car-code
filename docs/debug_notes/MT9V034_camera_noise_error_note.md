# MT9V034 总钻风摄像头严重噪点错误记录

## 1. 问题现象

- 图像出现大量黑白椒盐噪点。
- 局部有大面积过曝白块。
- 噪点会影响白线识别、矩形识别和状态机判断。
- 不能把噪点问题误判为 S1/S2/S3 状态机问题。

## 2. 当前参数

```text
MT9V03X_AUTO_EXP_DEF = 63
MT9V03X_EXP_TIME_DEF = 800
MT9V03X_FPS_DEF = 50
MT9V03X_GAIN_DEF = 64
```

`AUTO_EXP` 当前值接近/达到范围上限。`GAIN` 当前值为 64，是当前注释范围上限，属于噪点高优先级嫌疑项。

## 3. 可能原因

- 自动曝光过强。
- 增益过高。
- 光源直射或白胶带反光导致过曝。
- VCCCAM 不稳。
- GND 接触不好。
- 摄像头排线松动或干扰。
- PCLK / VSYNC / 数据线采集不稳定。
- `display_image` 去噪或状态栏导致误判原始图情况。
- 图像缓存被代码错误写入。

## 4. 排查顺序

1. 先看纯 raw 图。
2. 关闭显示去噪，确认 DAP 图是不是原始灰度 + 状态栏。
3. 检查每帧是否 `memcpy` `mt9v03x_image` 到 `work_image` 和 `display_image`。
4. 检查是否写坏 `mt9v03x_image`。
5. 检查自动曝光。
6. 检查增益。
7. 检查 VCCCAM。
8. 检查 GND。
9. 检查排线。
10. 改变光照，避免直射和反光。
11. 最后才考虑 `display_image` 显示层去噪。
12. 不要优先改状态机和识别阈值。

## 5. 防错提示

- `DEBUG_UART` 用于 DAP 图传，不能输出普通文本。
- `mt9v03x_image` 只能读，不能写。
- `work_image` 用于识别，不要画图。
- `display_image` 用于显示，可以状态栏和显示去噪。
- `VISION_OBJECT_OVERLAY_ENABLE` 默认保持 `0U`。
- 噪点严重时，先查曝光、增益、供电、排线、光照，不要先改状态机。
