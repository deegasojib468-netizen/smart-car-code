CYT4BB7 CM7_1 白框识别 V4.5：无线串口自动连续图传版

本版本基于 V4.4 修改：
1. 程序启动并初始化摄像头成功后，不需要按键，自动连续发送当前实时图像。
2. 图像发送通道仍为无线串口模块 UART1。
3. 为避免干扰逐飞助手“图像传输”解析，自动图传时只发送图像包，不再混入文字统计信息。
4. S6 / P20.0 仍可手动触发发送一帧。

无线串口接口：
- UART1
- MCU RX：P4.0
- MCU TX：P4.1
- RTS：P22.6
- 模块供电：主板 P7 的 VCC5V_EXT/GND

使用流程：
1. 插好无线串口模块。
2. IAR 先 Rebuild cyt4bb7_cm_7_1 - Debug。
3. 再 Rebuild cyt4bb7_cm_7_0 - Debug。
4. 保持 cyt4bb7_cm_7_0 为 Active，Download and Debug，然后 Run。
5. 断开 DAP 时，先断电，再拔 DAP，再只接电池重新上电。
6. 打开逐飞助手 → 图像传输 → 串行端口 → 选择无线接收端 COM 口，115200，8-N-1。
7. 程序会自动连续发送图像，左下角“字节数/秒”应大于 0。

重要说明：
188×120 灰度图约 22560 字节，115200 波特率下完整传一张图需要约 2 秒左右，
所以 FPS 很低是正常现象。这个版本用于调试观察图像，不适合作为正式比赛高速通信方案。
正式比赛建议只传 valid、center_x、error_x、width、height 等识别结果。
