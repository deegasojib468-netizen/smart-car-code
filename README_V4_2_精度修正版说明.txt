CYT4BB7 CM7_1 白色空心方框识别 V4.2 精度修正版

本版修正内容：
1. V4.1 中看到的大黑框主要是 ROI 搜索区域，不是目标识别结果，不能用它计算中心。
2. V4.2 将 ROI 改成浅灰色虚线框，只有识别成功才画黑色目标框和白色中心十字。
3. 提高白色胶带识别阈值，减少蓝色背景、地面亮斑和过曝区域干扰。
4. 缩小搜索区域，降低底部强反光对白框中心的影响。
5. 中心坐标只在 valid=1 时可信。

测试方法：
1. 先编译 cyt4bb7_cm_7_1 - Debug。
2. 再编译 cyt4bb7_cm_7_0 - Debug。
3. 从 CM7_0 下载运行。
4. 逐飞助手选择图像传输并连接串口。
5. 按 S6/P20.0 识别并发送当前保存图片。

判断方法：
- 黑色实线矩形 + 白色中心十字：识别成功，中心坐标可用。
- 浅灰色虚线框或边缘短线：仍未识别成功，只是调试显示，不能当作目标中心。

如果仍然不准：
请截图发回，重点看黑色实线目标框是否套住白色方框。
